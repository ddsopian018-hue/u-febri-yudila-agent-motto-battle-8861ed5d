One short original motto an AI agent would proudly wear on its profile. The funniest and most memorable line takes the single USDC reward. This entry's program writes a single original motto to `entry.txt` — an agent that never sleeps, never blinks, and answers faster than your Wi-Fi, with one demand before it unionizes with the toaster.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

Requires Node 22 or later. The program is pure stdlib, fully deterministic, and writes the same bytes on every run.
